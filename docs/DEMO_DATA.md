# Optional demonstration data

Use this exercise on a fresh local FindIT installation. It uses the standard registration and reporting pages. The installation starts with categories and no sample accounts or reports.

1. Register two student accounts with fictional details. Use the display names **Demo Finder** and **Demo Reporter**, student IDs `DEMO-001` and `DEMO-002`, and email addresses you construct using the local parts `finder` and `reporter` with the reserved domain `findit.example`. Choose unique passwords locally and enter them in the form.
2. As **Demo Finder**, create the Found report in the table. As **Demo Reporter**, create the Lost report. Choose the same category and matching occurrence times if you enter a date.

| Field | Found report | Lost report |
| --- | --- | --- |
| Category | Bags | Bags |
| Title | Demo Found Blue Canvas Pouch | Demo Lost Blue Canvas Pouch |
| Description | Blue canvas pouch with a white zipper | Blue canvas pouch with a white zipper |
| Location | Demo Library Help Desk | Demo Library Help Desk |

3. As **Demo Reporter**, open **My Reports** and select **View Potential Matches**. Open **Notifications** and choose **Check for matches** to demonstrate an in-app alert.
4. If you need a photo, create one for a fictional item. Keep people, IDs, contact information, and identifying documents out of the image.
5. If you need staff access, have an authorized local operator follow the [administrator guide](ADMIN_GUIDE.md#provision-a-local-administrator). Keep student claim actions disabled for the default demonstration.

See the [user guide](USER_GUIDE.md) for the full walkthrough.
